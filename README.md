# NonSense Repacks — сайт

Статический каталог репаков. Страницы **генерируются заранее** скриптом
`site_build.py` из Repack Studio — руками тут ничего править не нужно,
при следующей публикации перезапишется.

```
index.html          каталог, генерируется
about/index.html    о репаках, генерируется
r/<игра>/index.html страница релиза, генерируется
sitemap.xml         генерируется
data/releases.json  все релизы — источник для генерации
assets/style.css    оформление, чёрно-белое
assets/app.js       поиск в каталоге и просмотр скриншотов
images/<игра>/      обложка и скриншоты из Steam
```

## Почему страницы, а не один SPA

Сначала всё рисовал JavaScript из `releases.json`. Для человека разницы нет,
а для поисковика страниц просто не существовало: `#/r/among-us` — это якорь
внутри одной страницы, а не адрес. Краулер видел 118 символов текста и ноль
упоминаний игр.

Теперь у каждой игры настоящий адрес со всем текстом внутри: описание,
требования, что в репаке. Плюс своя карточка для ссылок — при отправке в
Telegram разворачивается обложка именно этой игры, а не общий логотип.

JavaScript остался только на то, что действительно нужно на клиенте: фильтр
поиска и разворот скриншота. Без него сайт работает, просто без этих двух
удобств.

## Как добавляется релиз

Данные об игре тянутся из открытого Steam API по ссылке на магазин, которая
уже лежит в файле репака: описание, жанр, разработчик, дата выхода,
системные требования, обложка и скриншоты. Руками задаётся только то, чего
Steam знать не может — что в репаке изменено и ссылки на раздачу.

Всё это делает кнопка **«Опубликовать на сайт»** в Repack Studio. Она же
пересобирает страницы и sitemap.

## Почему магнет, а не torrent-файл

Магнет — это строка с хешем, файла в репозитории нет. `.torrent` на игры
регулярно собирают DMCA, и вместе с репозиторием может прилететь аккаунту.
Сами раздачи живут на трекере, сайт только показывает каталог.

## Проверить локально

```bash
python -m http.server 8731
```

Потом открыть `http://127.0.0.1:8731`.

## Публикация

Settings → Pages → Deploy from branch → `main`, папка `/`.
Адрес получится `https://not1024.github.io/NonSense`.

Чтобы попасть в поиск быстрее — закинь сайт в Google Search Console
и нажми «Проверить URL → Запросить индексирование».
