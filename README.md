# NonSense Repacks — сайт

Статический каталог репаков. Никаких сборок и зависимостей: три файла и JSON.

```
index.html          разметка
assets/style.css    оформление, чёрно-белое
assets/app.js       каталог, поиск, страница релиза, about
data/releases.json  все релизы — генерируется Repack Studio
images/<игра>/      обложка и скриншоты из Steam
```

## Как добавляется релиз

Данные об игре тянутся из открытого Steam API по ссылке на магазин, которая
уже лежит в файле репака: описание, жанр, разработчик, дата выхода,
системные требования, обложка и скриншоты. Руками задаётся только то, чего
Steam знать не может — что в репаке изменено и ссылки на раздачу.

Запись в `releases.json` выглядит так:

```json
{
  "slug": "among-us",
  "title": "Among Us",
  "version": "2026.8.181",
  "revision": 1,
  "sizes": { "original": "1.2 ГБ", "repack": "254 МБ" },
  "features": ["Ничего не вырезано", "Мультиплеер через OnlineFix"],
  "downloads": {
    "magnet": "magnet:?xt=urn:btih:...",
    "mirrors": [{ "label": "Rutor", "url": "https://..." }]
  }
}
```

Поле `magnet` пустое — на странице просто написано «Ссылка скоро появится»,
кнопка неактивна. Ничего не ломается.

## Почему магнет, а не torrent-файл

Магнет — это строка с хешем, файла в репозитории нет. `.torrent` на игры
регулярно собирают DMCA, и вместе с репозиторием может прилететь аккаунту.
Сами раздачи живут на трекере, сайт только показывает каталог.

## Проверить локально

```bash
python -m http.server 8731
```

Потом открыть `http://127.0.0.1:8731`. Просто открыть `index.html` файлом
не выйдет: браузер не даст странице прочитать `releases.json`.

## Публикация

Settings → Pages → Deploy from branch → `main`, папка `/`.
Адрес получится `https://not1024.github.io/NonSense`.
